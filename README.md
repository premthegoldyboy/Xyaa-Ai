# OpenJarvis Android

This branch contains a native Android client and pins the original upstream OpenJarvis project as a Git submodule at `openjarvis/`. The backend, agents, inference, tools, and memory remain the upstream OpenJarvis implementation; no XYAA application code is used on this branch.

Clone with submodules: `git clone --branch openjarvis-android-alternative --recurse-submodules https://github.com/premthegoldyboy/Xyaa-Ai.git`.

See [android/README.md](android/README.md) for setup and build instructions.
